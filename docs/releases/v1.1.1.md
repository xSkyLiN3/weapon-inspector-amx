## Reliability and release hardening

Version 1.1.1 is a backward-compatible maintenance release. Existing CVARs, configuration files and public API names remain unchanged.

### Fixes

- Corrects native registration so API calls receive their parameters reliably.
- Enforces `ADMIN_RCON` on every administrative command.
- Releases cached sequence arrays before rebuilding the cache with `wi_reload_config`.
- Declares the Engine module required for impulse activation.
- Standardizes source, plugin and release artifact names.

### Build

The release asset is compiled from source with AMX Mod X 1.10.0.5478 by the repository workflow. It contains the compiled plugin, source, developer include and configuration templates.
