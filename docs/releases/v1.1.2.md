# Weapon Inspector v1.1.2

Version 1.1.2 is a correctness and release-hardening update. It does not add new gameplay features or rename existing CVARs, configuration keys or public API symbols.

## Runtime correctness

- Uses Counter-Strike's relative predicted-weapon timebase for idle delays.
- Makes the master enable switch bypass hooks and cancel active inspections.
- Enforces busy windows for API-forced inspections.
- Preserves normal weapon behavior when a viewmodel is unsupported.
- Uses the active weapon entity's bodygroup when playing an animation.

## Parser safety

- Validates Studio magic, version, declared length and sequence-table bounds.
- Reads the documented `numframes` field instead of applying a fallback heuristic.
- Rejects overlong INI sections and keys rather than indexing outside local buffers.

## Distribution

- Relicenses project code as GNU GPL version 3 or later to align with AMX Mod X plugin-distribution terms.
- Builds the plugin twice, produces a deterministic ZIP twice and compares both results.
- Publishes `SHA256SUMS.txt` with the release ZIP.

See [the validation matrix](../validation.md) for the exact automated and runtime evidence available before this release is tagged.
